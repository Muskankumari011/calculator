# 🔢 Stylish Calculator

A responsive and modern calculator built using **HTML**, **CSS**, and **Vanilla JavaScript**.  
Designed to mimic a real calculator layout with a sleek, dark-themed UI.

---


## 🎯 Features

- Clean and responsive layout
- Real calculator grid layout (C, ⌫, operators, digits, equals, decimal)
- Backspace and clear functionality
- Live expression evaluation
- Prevents invalid decimal entries
- Keyboard accessible (ARIA attributes included)
- Animated hover effects for a smooth UX

---

## 💻 Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling with Grid Layout & Hover Transitions
- **JavaScript (ES6)** — Core functionality and evaluation logic

---
